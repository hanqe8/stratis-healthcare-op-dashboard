# KPI Tree

## North Star

Reduce discharge cycle time without compromising operational governance.

## KPI Linkage

- Discharge cycle time
- Blocked discharge count
- Blocker age
- SLA breach count
- Bed-release risk
- Escalation closure rate
- Blocker category concentration
- Accountable owner load

## Decision Use

The KPI tree makes the operational path from blocker signal to owner action explicit. It is designed to support prioritisation, not clinical judgement.

## Interactive Views

The MVP supports Daily, Weekly, and Monthly cycle-time contribution views. These are deterministic synthetic operating views, not forecasts. Clicking a blocker category opens a drill-down showing the contributing cases, blockers, owners, risk levels, and contribution points.
