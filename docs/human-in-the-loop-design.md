# Human-in-the-Loop Design

## Principle

The system recommends; humans decide.

## Actions

- Accept: reviewer agrees with the recommendation.
- Override: reviewer chooses a different path and must provide rationale.
- Escalate: reviewer escalates for higher-level attention and must provide rationale.
- Resolve: reviewer records operational closure.
- Reject: reviewer rejects the recommendation.

## Rationale Controls

Overrides and escalations require rationale because they materially change the operating path or leadership burden.

## Governance

Every human action creates a governance event linked to the case and recommendation.
